# 🌈 Rainbow Bounce

**An interactive experiment by Frammary.**

Rainbow Bounce is a creative web experiment where words bounce around the screen, collide with a colorful laser, and react with visual and audio effects.

### ✨ Features
- 🌈 Customizable laser colors and styles
- ⚡ Bouncing words and collision effects
- 💥 Particle effects and sound effects
- 🔊 Text-to-speech when words interact with the laser
- 🎨 Customizable typography and movement
- 📝 Support for up to 50 words

### 🛠️ Built with
- HTML
- CSS
- JavaScript

Rainbow Bounce is the beginning of Frammary's journey into creative web development, interactive experiments, and original digital projects.
